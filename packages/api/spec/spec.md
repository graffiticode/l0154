# L0154 Specification

L0154 is a Graffiticode language for magic square math puzzles.

## Functions

### initializeGrid

Initializes a grid for the magic square with the given dimensions and configuration.

**Syntax:** `initializeGrid <config> <puzzle>`

### showFeedback

Controls whether feedback is shown for student responses.

**Syntax:** `showFeedback <enabled> <puzzle>`

### magicSquare

Creates a magic square puzzle visualization.

**Syntax:** `magicSquare <config> <problem>`

### problemStatement

Sets the problem statement text displayed to the student.

**Syntax:** `problemStatement <text>`

### expression

Sets the mathematical expression or constraint for the puzzle.

**Syntax:** `expression <expr>`

### table

Configures the table layout for the magic square grid.

**Syntax:** `table <config> <puzzle>`

### cols

Sets the number of columns in the magic square grid.

**Syntax:** `cols <count>`

### rows

Sets the number of rows in the magic square grid.

**Syntax:** `rows <count>`
